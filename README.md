# Amma Bojanam - Restaurant Website

A beautiful, modern, and responsive website for the "Amma Bojanam" restaurant, featuring authentic Indian cuisine.

## 🌟 Features

### Design & User Experience
- **Modern & Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Beautiful Animations**: Smooth scroll animations and hover effects
- **Professional Typography**: Uses Google Fonts (Playfair Display & Poppins)
- **Color Scheme**: Warm red and dark blue theme representing Indian culture

### Navigation & Functionality
- **Fixed Navigation Bar**: Always accessible with smooth scrolling
- **Mobile-Friendly Menu**: Hamburger menu for mobile devices
- **Interactive Menu Filtering**: Filter menu items by category (Starters, Main Course, Breads, Desserts)
- **Contact Form**: Functional contact form with validation
- **Scroll to Top Button**: Easy navigation back to the top

### Content Sections
1. **Hero Section**: Eye-catching introduction with call-to-action buttons
2. **Features**: Highlighting restaurant's unique selling points
3. **Menu**: Interactive menu with categories and beautiful food images
4. **About**: Restaurant story and background
5. **Contact**: Contact information and contact form
6. **Footer**: Social links and additional information

### Technical Features
- **Cross-Browser Compatible**: Works on all modern browsers
- **SEO Optimized**: Proper HTML structure and meta tags
- **Fast Loading**: Optimized images and efficient code
- **Accessibility**: Keyboard navigation and screen reader friendly

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No additional software required

### Installation
1. Download or clone the repository
2. Open `index.html` in your web browser
3. The website will load immediately

### File Structure
```
restaurent/
├── index.html          # Main HTML file
├── styles.css          # CSS styles and responsive design
├── script.js           # JavaScript functionality
└── README.md           # This file
```

## 🎨 Customization

### Changing Colors
The website uses a warm red color scheme. To change colors, edit the CSS variables in `styles.css`:
- Primary color: `#e74c3c` (red)
- Secondary color: `#2c3e50` (dark blue)
- Text color: `#333` (dark gray)

### Adding Menu Items
To add new menu items, edit the menu section in `index.html`:
1. Copy an existing menu item structure
2. Change the image URL, title, description, and price
3. Set the appropriate `data-category` attribute

### Updating Content
- **Restaurant Name**: Change "Amma Bojanam" throughout the HTML
- **Contact Information**: Update address, phone, email in the contact section
- **Menu Items**: Add, remove, or modify menu items as needed
- **Images**: Replace image URLs with your own restaurant photos
